# AutoFlow

Free Windows desktop automation — capture the screen, connect steps, and automate repetitive work.

**Official distribution repository. The proprietary application source is not hosted here.**

## Download

[Download AutoFlow for Windows x64](https://github.com/bonolabs/autoflow/releases/latest/download/AutoFlow-Setup.exe)

[All releases, corresponding third-party sources and SHA-256 checksums](https://github.com/bonolabs/autoflow/releases)

AutoFlow 0.1.0 is now available.
Download AutoFlow-Setup.exe and run the installer. You do not need Python installed.

## Features

- Screen capture and image matching with mouse/keyboard actions
- Excel column placeholders and repeated input over data rows
- Repeated flow segments, dynamic date/time input and website launching
- Scheduled project execution, including after the app has closed on Windows
- Execution logs, partial execution, breakpoints and ESC to stop
- Local project storage and seven interface languages

Use Windows 10/11 x64 and keep automation targets on the primary monitor.
Scheduled screen automation requires the PC to be on, with Windows signed in and the desktop
unlocked. Prepare the target application before the scheduled time.
